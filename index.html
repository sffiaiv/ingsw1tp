FarmaClick: Sistema de Control de Stock y Ventas

Desarrollado para la Mini Farmacia Familiar de Doris

Sobre el Proyecto

Este repositorio aloja el código fuente y la documentación del sistema informático desarrollado como proyecto de programación académica. El propósito de este sistema es modernizar la gestión de la farmacia de la señora Doris.

Objetivo principal: Automatizar el registro de ventas, gestionar el inventario de medicamentos de forma centralizada y emitir alertas preventivas de bajo stock y medicamentos próximos a vencer.
